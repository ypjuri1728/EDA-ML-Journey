# Working with CSV

This folder contains my practice for working with CSV files using Python and Pandas.

## Topics Covered

* Reading CSV files
* Viewing data
* Checking rows and columns
* Basic data analysis
* Working with CSV data using Pandas

## Tools Used

* Python
* Pandas
* Jupyter Notebook / Google Colab

## Purpose

To learn how to load, explore, and work with CSV datasets before performing further data analysis and machine learning tasks.

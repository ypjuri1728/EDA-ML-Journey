# API to DataFrame

This folder contains my practice of working with **APIs** and converting API data into a **Pandas DataFrame**.

## Topics Covered

* What is an API
* Fetching data from an API
* Working with JSON data
* Converting API data into a DataFrame
* Basic Pandas operations on API data

## Tools Used

* Python
* Pandas
* Requests
* Jupyter Notebook / Google Colab

## Learning Goal

To learn how to collect data from an API and work with it using Pandas DataFrames.
